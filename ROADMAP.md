# Roadmap

M3Quiz is moving from a personal static quiz into a maintainable open-source question bank and learning tool.

## Now — dataset trust

- Audit exact and near-duplicate questions
- Correct contradictory answers and unit errors
- Separate observed facts from Fermi assumptions
- Add source and access-date conventions
- Keep automated validation mandatory for pull requests

## Next — contributor experience

- Add structured source fields without breaking static deployment
- Provide a question-authoring form or generator
- Publish contribution examples for each question type
- Add accessibility and keyboard-navigation tests
- Create documented semantic releases and changelogs

## Later — reusable ecosystem tooling

- Export the dataset as CSV and JSON
- Add stable category and difficulty metadata
- Provide embeddable quiz components
- Support multilingual question variants
- Build human-reviewed AI-assisted workflows for duplicate detection, wording review, and issue triage

## Non-goals

- Reproducing confidential or copyrighted hiring assessments
- Automatically publishing AI-generated questions without human review
- Presenting Fermi estimates as authoritative statistics
- Optimizing for question count at the expense of provenance and quality

Roadmap priorities may change based on contributor feedback and dataset audit findings.
